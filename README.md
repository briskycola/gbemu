# Game Boy Emulator
This will be my attempt to port my already existing
Game Boy Emulator to C++. The goal is to take advantage
of modern C++ features and to use OOP. I already have
progress with some of the components, but this will
be my start with source control. I may end up reimplementing
some logic entirely. I'll update the README once
I'm confident that the emulator is in a good state.
